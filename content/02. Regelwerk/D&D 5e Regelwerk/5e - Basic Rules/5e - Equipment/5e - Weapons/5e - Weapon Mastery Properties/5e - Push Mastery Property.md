# 🗡️5e - Push Mastery🗡️

If you _**hit**_ a creature with this weapon, you can [[02. Regelwerk/D&D 5e Regelwerk/5e - Basic Rules/5e - Adventuring/5e - Movement/5e - Pushing|🏃‍♀️Push]] the creature up to <u>10 feet</u> straight away from yourself if it is _Large or smaller_.
