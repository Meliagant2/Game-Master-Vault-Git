# 🎲5e - Disadvantage🎲

If you have **Disadvantage (ADV)** on a [[02. Regelwerk/D&D 5e Regelwerk/5e - Basic Rules/5e - D20 Tests/5e - D20 Tests|🎲D20 Test]], roll <u>two</u> `d20s`, and use the _lower_ roll. A roll can't be affected by more than one **Disadvantage**, and **Disadvantage** and [[02. Regelwerk/D&D 5e Regelwerk/5e - Basic Rules/5e - D20 Tests/5e - ADV & DISADV/5e - Advantage|🎲Advantage]] on the same roll cancel each other.
