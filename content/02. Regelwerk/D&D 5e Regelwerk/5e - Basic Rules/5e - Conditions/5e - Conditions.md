# ☠️5e - Conditions☠️

A condition is a temporary game state. The definition of a condition says how it affects its recipient, and various rules define how to end a condition. A condition doesn't stack with itself; a recipient either has a condition or doesn't. The [[02. Regelwerk/D&D 5e Regelwerk/5e - Basic Rules/5e - Conditions/5e - Exhaustion|☠️Exhaustion]] condition is an exception to that rule.
