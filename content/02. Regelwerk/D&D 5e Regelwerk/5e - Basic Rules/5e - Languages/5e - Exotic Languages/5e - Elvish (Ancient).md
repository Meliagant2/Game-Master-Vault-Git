# 🗣️5e - Elvish (Ancient)🗣️

> [!wikibox]
>
> | | |
> |---|---|
> |**Category** |Exotic |
> |**Origin** |Alkrat \[Aylivar] |
> |**Language Family** |Fay |

Ancient Elvish, called **Ayvaris** in its native words, is the long lost language spoken by the _Aylivar_, the first elven culture, that walked the world. Since buildings and way shrines of this ancient civilization are found all over the _Yetem_ continent, it is possible to learn this language, if one is interested in historic languages.
