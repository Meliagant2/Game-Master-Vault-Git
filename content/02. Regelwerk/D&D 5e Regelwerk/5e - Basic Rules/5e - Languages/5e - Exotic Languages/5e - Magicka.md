# 🗣️5e - Magicka🗣️

> [!wikibox]
>
> | | |
> |---|---|
> |**Category** |Exotic |
> |**Origin** |Scholars of the Arcane |
> |**Language Family** |Thu´um |

Magicka is a language, constructed by an ancient Elvish civilization, to create arcane magic. It is a very complicated, but logical language. To write long texts in this language is not worth the effort, since it takes incredibly long to do so and later a long time to decipher the text. It normally is only used to create magical glyphs.
