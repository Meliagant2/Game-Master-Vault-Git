# ⚔️5e - Utilize⚔️

You normally interact with an object while doing something else, such as when you draw a sword as part of the [[02. Regelwerk/D&D 5e Regelwerk/5e - Combat/5e - Actions, Bonus Actions & Reactions/5e - Actions/5e - Attack Action|⚔️Attack]] action. When an object requires an action for its use, you take the Utilize action.
