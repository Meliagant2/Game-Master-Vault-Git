# 🥇5e - Voice Specialty🥇

> [!wikibox]
> | | |
> |---|---|
> |**Category**|Class |
> |**Level Requirement**|2 |
> |**Prerequisite**|Bard |
> |**Repeatable**| |

You gain the following benefits:

**<u>Instrument Proficiency:</u>** You gain proficiency with one [[02. Regelwerk/D&D 5e Regelwerk/5e - Basic Rules/5e - Equipment/5e - Spellcasting Focus/5e - Musical Instruments/5e - Musical Instruments|🛠️Musical Instrument]] of your choice. Alternatively, you gain an <u>expertise die</u> for one <u>Musical Instrument</u> you are already proficient in.

**<u>Verbal Casting:</u>** When using this musical art as a spell focus, you can add an <u>expertise die</u> to checks made to maintain **concentration** on a Bard spell, that has Verbal components.

> [!info] Feat "Upgrades"
> Taking this Feat allows you, to take the [[02. Regelwerk/D&D 5e Regelwerk/5e - Character Creation/5e - 03. Feats/5e - Class Feats/5e - Class Feats; Bard/5e - Everlasting Song|🥇Everlasting Song]] Feat Later
