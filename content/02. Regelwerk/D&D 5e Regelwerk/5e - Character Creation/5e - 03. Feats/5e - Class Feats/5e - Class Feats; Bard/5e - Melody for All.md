# 🥇5e - Melody for All🥇

> [!wikibox]
> | | |
> |---|---|
> |**Category**|Class |
> |**Level Requirement**|8 |
> |**Prerequisite**|Bard, String Instrument Specialty |
> |**Repeatable**| |

When using a string instrument as a spell focus, if you cast a spell that targets only one creature you can target an additional creature within the spell’s range.

**<u>Number of Uses:</u>** You can use this feature a number of times equal to `your CHA`, and you regain all expended uses when you finish a **Short Rest**.
