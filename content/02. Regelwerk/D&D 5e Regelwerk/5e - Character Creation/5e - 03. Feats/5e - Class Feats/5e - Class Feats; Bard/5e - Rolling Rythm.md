# 🥇5e - Rolling Rythm🥇

> [!wikibox]
> | | |
> |---|---|
> |**Category**|Class |
> |**Level Requirement**|8 |
> |**Prerequisite**|Bard, Percussion Specialty |
> |**Repeatable**| |

When using a percussion instrument as a spell focus, you can target an additional creature within range of the first (as if it were casting the spell).

**<u>Number of Uses:</u>** You can use this feature a number of times equal to `your CHA`, and you regain all expended uses when you finish a **Short Rest**.
