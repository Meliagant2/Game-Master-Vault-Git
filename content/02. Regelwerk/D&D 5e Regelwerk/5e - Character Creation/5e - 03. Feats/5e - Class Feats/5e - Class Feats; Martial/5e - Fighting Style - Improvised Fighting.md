# 🥇5e - Fighting Style - Improvised Fighting🥇

> [!wikibox]
> | | |
> |---|---|
> |**Category**|Class |
> |**Level Requirement**|1 |
> |**Prerequisite**|Martial Class |

You gain the following benefits:

**<u>Known Improviser:</u>** You gain [[02. Regelwerk/D&D 5e Regelwerk/5e - Basic Rules/5e - D20 Tests/5e - Proficiency/5e - Proficiency|🎲Proficiency]] with [[02. Regelwerk/D&D 5e Regelwerk/5e - Basic Rules/5e - Equipment/5e - Weapons/5e - Improvised Weapons/5e - Improvised Weapons|🗡️Improvised Weapons]].

**<u>Improvised Damage:</u>** On a _**hit**_ your [[02. Regelwerk/D&D 5e Regelwerk/5e - Basic Rules/5e - Equipment/5e - Weapons/5e - Improvised Weapons/5e - Improvised Weapons|🗡️Improvised Weapons]] deal `2d4` damage of a type the GM thinks is appropriate for the object, instead of their normal `1d4`.

**<u>Reroll Damage:</u>** <u>Once per turn</u>, when you hit with a [[02. Regelwerk/D&D 5e Regelwerk/5e - Basic Rules/5e - Equipment/5e - Weapons/5e - Improvised Weapons/5e - Improvised Weapons|🗡️Improvised Weapon]], you can roll the <u>damage die</u> <u>twice</u> and take the <u>higher roll</u>.
