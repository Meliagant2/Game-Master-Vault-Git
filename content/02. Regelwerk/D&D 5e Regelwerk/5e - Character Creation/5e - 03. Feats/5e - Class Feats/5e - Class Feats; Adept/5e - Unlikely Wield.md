# 🥇5e - Unlikely Wield🥇

> [!wikibox]
> | | |
> |---|---|
> |**Category**|Class |
> |**Level Requirement**|6 |
> |**Prerequisite**|Adept |
> |**Repeatable**| |

You gain the following benefits:

You can wield <u>three</u> [[02. Regelwerk/D&D 5e Regelwerk/5e - Basic Rules/5e - Equipment/5e - Weapons/5e - Weapons|🗡️Weapons]] with the [[02. Regelwerk/D&D 5e Regelwerk/5e - Basic Rules/5e - Equipment/5e - Weapons/5e - Weapon Properties/5e - Light (Property)|🗡️Light]] property at once. Typically this is done with a [[02. Regelwerk/D&D 5e Regelwerk/5e - Basic Rules/5e - Equipment/5e - Weapons/5e - Swords/5e - Dagger|🗡️Dagger]] wielded between toes, but it has been known to be done with the mouth (or even a tail for combatants that have one). When you engage in [[02. Regelwerk/D&D 5e Regelwerk/5e - Combat/5e - Actions, Bonus Actions & Reactions/5e - Actions/5e - Two-Weapon Fighting|⚔️Two-Weapon Fighting]], you can use the third weapon to make an additional [[02. Regelwerk/D&D 5e Regelwerk/5e - Basic Rules/5e - D20 Tests/5e - Attack Roll/5e - Weapon Attack|🎲Weapon Attack]] as part of the same **Action** you use to make your regular extra attack for [[02. Regelwerk/D&D 5e Regelwerk/5e - Combat/5e - Actions, Bonus Actions & Reactions/5e - Actions/5e - Two-Weapon Fighting|⚔️Two-Weapon Fighting]].
