# 🥇5e - Beyond Size🥇

> [!wikibox]
> | | |
> |---|---|

You gain the following benefits:

**<u>No matter the Size:</u>** You have learned to use your opponents’ size against them. You can use [[02. Regelwerk/D&D 5e Regelwerk/5e - Combat/5e - Combat Maneuvers/5e - Combat Traditions/5e - Basic Maneuvers/5e - Basic Maneuvers|🤺Basic Maneuvers]] against creatures of _any size_.

**<u>Fell the Giants:</u>** If you _**fail**_ an [[02. Regelwerk/D&D 5e Regelwerk/5e - Basic Rules/5e - D20 Tests/5e - Ability Check/5e - Ability Check|🎲Ability Check]] for one of your [[02. Regelwerk/D&D 5e Regelwerk/5e - Combat/5e - Combat Maneuvers/5e - Combat Traditions/5e - Basic Maneuvers/5e - Basic Maneuvers|🤺Basic Maneuvers]], you can use your **Reaction** to reroll the [[02. Regelwerk/D&D 5e Regelwerk/5e - Basic Rules/5e - D20 Tests/5e - Ability Check/5e - Ability Check|🎲Check]] and use the new result.
