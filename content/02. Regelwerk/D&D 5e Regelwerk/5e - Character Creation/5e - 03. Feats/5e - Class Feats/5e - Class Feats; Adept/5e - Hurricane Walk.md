You gain the following benefits:

**<u>Floating Step:</u>** You can use a **Bonus Action** and spend `2` <u>Exertion</u> to cast [[02. Regelwerk/D&D 5e Regelwerk/5e - Combat/5e - Spellcasting/5e - Spell Schools/5e - Spellschool Transmutation/5e - Level 3 Transmutation/5e - Fly (Spell)|☄️Fly]] on yourself, without needing to [[02. Regelwerk/D&D 5e Regelwerk/5e - Basic Rules/5e - D20 Tests/5e - Saving Throw/5e - Concentration|🎲concentrate]] on it. The effect lasts for <u>3 turns</u>.

The casting of this feat's spell does **not** count as a magical effect. It is considered to be a _Maneuver_ effect instead.

**<u>Silent as the air:</u>** You have **ADV** on <u>Stealth</u> checks.
