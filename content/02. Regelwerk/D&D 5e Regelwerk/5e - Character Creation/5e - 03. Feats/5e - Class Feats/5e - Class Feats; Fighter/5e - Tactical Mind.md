# 🥇5e - Tactical Mind🥇

> [!wikibox]
> | | |
> |---|---|
> |**Category**|Class |
> |**Level Requirement**|4 |
> |**Prerequisite**|Fighter |
> |**Repeatable**| |

You gain the following benefits:

When you _**fail**_ an [[02. Regelwerk/D&D 5e Regelwerk/5e - Basic Rules/5e - D20 Tests/5e - Ability Check/5e - Ability Check|🎲Ability Check]], you can expend a use of your **Second Wind** to push yourself toward success. Rather than regaining [[02. Regelwerk/D&D 5e Regelwerk/5e - Combat/5e - Hit Points/5e - Hit Points|💖Hit Points]], you roll `1d10` and add the number rolled to the [[02. Regelwerk/D&D 5e Regelwerk/5e - Basic Rules/5e - D20 Tests/5e - Ability Check/5e - Ability Check|🎲Ability Check]], potentially turning it into a _success_. If the **check** still _fails_, this use of **Second Wind** isn't expended.
