# 🥇5e - Adaptive Tactics🥇

> [!wikibox]
> | | |
> |---|---|
> |**Category**|Class |
> |**Level Requirement**|6 |
> |**Prerequisite**|Fighter |
> |**Repeatable**| |

When you roll for [[02. Regelwerk/D&D 5e Regelwerk/5e - Combat/5e - Initiative|🎲Initiative]], and at <u>the end of each of your turns</u>, you gain a `d8` **Tactical Die** if you don’t already have one. You can spend a **Tactical Die** to gain one of the following Tactics:

**<u>Assault:</u>** When you make a [[02. Regelwerk/D&D 5e Regelwerk/5e - Basic Rules/5e - D20 Tests/5e - Attack Roll/5e - Weapon Attack|🎲Weapon Attack]], you can add the die to the [[02. Regelwerk/D&D 5e Regelwerk/5e - Basic Rules/5e - D20 Tests/5e - Attack Roll/5e - Attack Roll|🎲Attack Roll]].

**<u>Deflect:</u>** When you are [[02. Regelwerk/D&D 5e Regelwerk/5e - Basic Rules/5e - D20 Tests/5e - Attack Roll/5e - Attack Roll|🎲Attacked]], you can subtract the die from the [[02. Regelwerk/D&D 5e Regelwerk/5e - Basic Rules/5e - D20 Tests/5e - Attack Roll/5e - Attack Roll|🎲Attack Roll]].
