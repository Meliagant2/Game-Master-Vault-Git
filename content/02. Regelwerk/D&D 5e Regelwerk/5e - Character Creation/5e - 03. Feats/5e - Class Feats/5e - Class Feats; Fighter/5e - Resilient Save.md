# 🥇5e - Resilient Save🥇

> | | |

You gain the following benefits:

**<u>Bloodied Saves:</u>** If you _succeed_ on a <u>STR</u> or <u>CON Save</u> that would normally cause you to take _half_ damage on a _**success**_, you take _no damage_ instead.
