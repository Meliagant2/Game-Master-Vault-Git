# 🥇5e - Beyond Size🥇

> [!wikibox]
> | | |
> |---|---|

> |**Level Requirement**|10 |
> |**Prerequisite**|Adept |

You gain the following benefits:

**<u>No matter the Size:</u>** You have learned to use your opponents’ size against them. You can use [[02. Regelwerk/D&D 5e Regelwerk/5e - Combat/5e - Combat Maneuvers/5e - Basic Maneuvers/5e - Basic Maneuvers|🤺Basic Maneuvers]] against creatures of _any size_.

**<u>Fell the Giants:</u>** If a creature that is _larger_ than you saves against your [[02. Regelwerk/D&D 5e Regelwerk/5e - Combat/5e - Combat Maneuvers/5e - Basic Maneuvers/5e - Basic Maneuvers|🤺Basic Maneuver]], you can use your **Reaction** to make the creature reroll the <u>Save</u>.
