# 🥇5e - Shining Smite🥇

> [!wikibox]
> | | |
> |---|---|
> |**Category**|Class |
> |**Level Requirement**|6 |
> |**Prerequisite**|Paladin |
> |**Repeatable**| |

You gain the following benefits:

**<u>Illuminating Smite:</u>** When you use your **Paladin's Smite** and deal <u>Radiant</u> damage with it, the target makes a **repeated CHA Save**. _**Failure:**_ For <u>1 minute</u> the target sheds [[02. Regelwerk/D&D 5e Regelwerk/5e - Basic Rules/5e - Adventuring/5e - Vision and Light/5e - Illumination/5e - Bright Light|💡Bright Light]], has the [[02. Regelwerk/D&D 5e Regelwerk/5e - Basic Rules/5e - Conditions/5e - Exposed|☠️Exposed]] conditon, and can't benefit from the [[02. Regelwerk/D&D 5e Regelwerk/5e - Basic Rules/5e - Conditions/5e - Invisible|☠️Invisible]] condition.

If you have more than one feature that adds an effect to your **Paladin's Smite**, you can only use <u>one</u> of them per instance of smite.
