# 🥇5e - Blinding Smite🥇

> [!wikibox]
> | | |
> |---|---|
> |**Category**|Class |
> |**Level Requirement**|8 |
> |**Prerequisite**|Paladin |
> |**Repeatable**| |

You gain the following benefits:

**<u>Blinding Smite:</u>** When you use your **Paladin's Smite** and deal <u>Radiant</u> damage with it, the target has the [[02. Regelwerk/D&D 5e Regelwerk/5e - Basic Rules/5e - Conditions/5e - Blinded|☠️Blinded]] condition for <u>1 minute</u>. At <u>the end of each of its turns</u>, the target makes a **repeated CON Save**. _**Success:**_ The condition ends.

If you have more than one feature that adds an effect to your **Paladin's Smite**, you can only use <u>one</u> of them per instance of smite.
