# 🥇5e - Shocking Smite🥇

> [!wikibox]
> | | |
> |---|---|
> |**Category**|Class |
> |**Level Requirement**|2 |
> |**Prerequisite**|Paladin |
> |**Repeatable**| |

You gain the following benefits:

**<u>Electrocuting Smite:</u>** When you use your **Paladin's Smite**, you can deal <u>Lightning</u> damage with it, instead of its normal damage type. When you do so, the target has one stack of the [[02. Regelwerk/D&D 5e Regelwerk/5e - Basic Rules/5e - Conditions/5e - Electrocuted|☠️Electrocuted]] condition.

If you have more than one feature that adds an effect to your **Paladin's Smite**, you can only use <u>one</u> of them per instance of smite.
