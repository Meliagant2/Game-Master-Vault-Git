# 🥇5e - Wilting Smite🥇

> [!wikibox]
> | | |
> |---|---|
> |**Category**|Class |
> |**Level Requirement**|6 |
> |**Prerequisite**|Paladin |
> |**Repeatable**| |

You gain the following benefits:

**<u>Tearing Smite:</u>** When you use your **Paladin's Smite** and deal <u>Necrotic</u> damage with it, the target loses all <u>Resistances</u> to damage until <u>the start of your next turn</u>.

If you have more than one feature that adds an effect to your **Paladin's Smite**, you can only use <u>one</u> of them per instance of smite.
