# 🥇5e - Wrathful Smite🥇

> [!wikibox]
> | | |
> |---|---|
> |**Category**|Class |
> |**Level Requirement**|4 |
> |**Prerequisite**|Paladin |
> |**Repeatable**| |

You gain the following benefits:

**<u>Terrifying Smite:</u>** When you use your **Paladin's Smite**, you can deal <u>Psychic</u> damage with it, instead of its normal damage type. When you do so, the target makes a **repeated WIS Save**. _**Failure:**_ The target is [[02. Regelwerk/D&D 5e Regelwerk/5e - Basic Rules/5e - Conditions/5e - Frightened|☠️Frightened]] for <u>1 minute</u>.

If you have more than one feature that adds an effect to your **Paladin's Smite**, you can only use <u>one</u> of them per instance of smite.
