# 🥇5e - Bone-Chilling Smite🥇

> [!wikibox]
> | | |
> |---|---|
> |**Category**|Class |
> |**Level Requirement**|8 |
> |**Prerequisite**|Paladin |
> |**Repeatable**| |

You gain the following benefits:

**<u>Exhausting Smite:</u>** When you use your **Paladin's Smite** and deal <u>Necrotic</u> damage with it, the target gains one level of [[02. Regelwerk/D&D 5e Regelwerk/5e - Basic Rules/5e - Conditions/5e - Exhaustion|☠️Exhaustion]] for <u>1 minute</u>. At <u>the end of each of its turns</u>, the target makes a **repeated CON Save**. _**Success:**_ The target removes all stacks of [[02. Regelwerk/D&D 5e Regelwerk/5e - Basic Rules/5e - Conditions/5e - Exhaustion|☠️Exhaustion]] caused by this feature. _**Failure:**_ The target receives one level of [[02. Regelwerk/D&D 5e Regelwerk/5e - Basic Rules/5e - Conditions/5e - Exhaustion|☠️Exhaustion]].

If you have more than one feature that adds an effect to your **Paladin's Smite**, you can only use <u>one</u> of them per instance of smite.
