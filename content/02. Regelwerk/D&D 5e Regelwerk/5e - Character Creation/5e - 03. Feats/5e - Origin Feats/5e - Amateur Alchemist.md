# 🥇5e - Amateur Alchemist🥇

You gain the following benefits:

**<u>Decanting:</u>** When you finish a [[02. Regelwerk/D&D 5e Regelwerk/5e - Basic Rules/5e - Adventuring/5e - Resting/5e - Long Rest|😴Long Rest]], you can create one [[02. Regelwerk/D&D 5e Regelwerk/5e - Basic Rules/5e - Equipment/5e - Potions/5e - Healing Potion (Lv1)|🧉Healing Potion (Lv1)]] or an [[02. Regelwerk/D&D 5e Regelwerk/5e - Basic Rules/5e - Equipment/5e - Elixirs/5e - Antitoxin|🍶Antitoxin]], as long as you have an empty [[02. Regelwerk/D&D 5e Regelwerk/5e - Basic Rules/5e - Equipment/5e - Adventuring Gear/5e - Vial|🪓Vial]] or [[02. Regelwerk/D&D 5e Regelwerk/5e - Basic Rules/5e - Equipment/5e - Adventuring Gear/5e - Flask|🪓Flask]]. These liquids evaporate when you finish another **Long Rest**.

**<u>Timely Retreat:</u>** You can take a **Bonus Action** to take the [[02. Regelwerk/D&D 5e Regelwerk/5e - Combat/5e - Actions, Bonus Actions & Reactions/5e - Actions/5e - Dash|⚔️Dash]] action or the [[02. Regelwerk/D&D 5e Regelwerk/5e - Combat/5e - Actions, Bonus Actions & Reactions/5e - Actions/5e - Disengage|⚔️Disengage]] action.

You can use this benefit a number of times equal to <u>your Proficiency Bonus</u>, and you regain all expended uses when you finish a [[02. Regelwerk/D&D 5e Regelwerk/5e - Basic Rules/5e - Adventuring/5e - Resting/5e - Long Rest|😴Long Rest]].
