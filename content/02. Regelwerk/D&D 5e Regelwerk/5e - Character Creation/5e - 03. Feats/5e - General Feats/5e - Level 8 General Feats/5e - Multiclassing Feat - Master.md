# 🥇5e - Multiclassing Feat - Master🥇

> [!wikibox]
> | | |
> |---|---|
> |**Category**|General |
> |**Level Requirement**|8 |
> |**Prerequisite**| |

You gain **one** of the following from a Class that you have at least 2 Class Feature from:

**<u>Level 5 Feature:</u>** You gain **one** level 5 Class Feature from that Class, that you don't already have.

**<u>Class Feat:</u>** You gain a level 2, level 4, or level 6 [[02. Regelwerk/D&D 5e Regelwerk/5e - Character Creation/5e - 03. Feats/5e - Class Feats/5e - Class Feats|🥇Class Feat]] from that Class, that you don't already have.

**<u>Subclass Feature:</u>** You gain the level 7 Subclass Feature of a Subclass you have the Level 3 Subclass Feature from.
