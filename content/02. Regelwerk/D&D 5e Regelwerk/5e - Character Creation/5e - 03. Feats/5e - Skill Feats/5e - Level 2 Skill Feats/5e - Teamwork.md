# 🥇5e - Teamwork🥇

> [!wikibox]
> | | |
> |---|---|
> |**Category**|Skill |
> |**Level Requirement**|2 |
> |**Prerequisite**|CHA +1 |
> |**Repeatable**| |

You gain the following benefits:

**<u>Skill Proficiency:</u>** You gain [[02. Regelwerk/D&D 5e Regelwerk/5e - Basic Rules/5e - Skills/5e - CHA Skills/5e - Persuasion|💃Persuasion]] [[02. Regelwerk/D&D 5e Regelwerk/5e - Basic Rules/5e - D20 Tests/5e - Proficiency/5e - Proficiency|🎲Proficiency]], or one level of [[02. Regelwerk/D&D 5e Regelwerk/5e - Basic Rules/5e - D20 Tests/5e - Proficiency/5e - Expertise|🎲Expertise]], if you are already _proficient_.

**<u>Inspiring Willpower:</u>** If you _succeed_ on a [[02. Regelwerk/D&D 5e Regelwerk/5e - Basic Rules/5e - D20 Tests/5e - Saving Throw/5e - Saving Throw|🎲Save]] to end the [[02. Regelwerk/D&D 5e Regelwerk/5e - Basic Rules/5e - Conditions/5e - Frightened|☠️Frightened]] or [[02. Regelwerk/D&D 5e Regelwerk/5e - Basic Rules/5e - Conditions/5e - Paralyzed|☠️Paralyzed]] condition on yourself, you can choose one ally you can _see_ within <u>30 feet</u> of yourself that has the same condition. That condition immediately ends for that ally.
