You gain the following benefits:

**<u>Skill Proficiency:</u>** You gain [[02. Regelwerk/D&D 5e Regelwerk/5e - Basic Rules/5e - Skills/5e - Knowledge Skills/5e - History|💃History]] [[02. Regelwerk/D&D 5e Regelwerk/5e - Basic Rules/5e - D20 Tests/5e - Proficiency/5e - Proficiency|🎲Proficiency]], or one level of [[02. Regelwerk/D&D 5e Regelwerk/5e - Basic Rules/5e - D20 Tests/5e - Proficiency/5e - Expertise|🎲Expertise]], if you are already _proficient_.

**<u>Book Learning:</u>** If you touch an object containing a script for <u>1 minute</u>, you learn a basic, working knowledge of the script's contents unless that information is hidden by a code or cypher. If the book or script is a _magic item_ or _magical object_, you learn its properties and how to use it, whether it requires [[02. Regelwerk/D&D 5e Regelwerk/5e - Basic Rules/5e - Equipment/5e - Attunement/5e - Attunement|☄️Attunement]], and how many _charges_ it has, if any. You learn whether any ongoing _spells_ are affecting the item and what they are. If the item was created by a _spell_, you learn that _spell's_ name.
