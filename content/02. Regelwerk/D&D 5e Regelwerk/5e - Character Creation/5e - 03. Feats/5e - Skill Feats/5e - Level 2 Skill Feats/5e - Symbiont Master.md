# 🥇5e - Symbiont Master🥇

> [!wikibox]
> | | |
> |---|---|

> |**Level Requirement**|2 |
> |**Prerequisite**|INT +1 |

You gain the following benefits:

**<u>Skill Proficiency:</u>** You gain [[02. Regelwerk/D&D 5e Regelwerk/5e - Basic Rules/5e - Skills/5e - Knowledge Skills/5e - Arcana|💃Arcana]] [[02. Regelwerk/D&D 5e Regelwerk/5e - Basic Rules/5e - D20 Tests/5e - Proficiency/5e - Proficiency|🎲Proficiency]], or one level of [[02. Regelwerk/D&D 5e Regelwerk/5e - Basic Rules/5e - D20 Tests/5e - Proficiency/5e - Expertise|🎲Expertise]], if you are already _proficient_.

**<u>Symbiont Mastery:</u>** You can [[02. Regelwerk/D&D 5e Regelwerk/5e - Basic Rules/5e - Equipment/5e - Attunement/5e - Attunement|☄️Attune]] to <u>one</u> _magic item_ that has the [[02. Regelwerk/D&D 5e Regelwerk/5e - Basic Rules/5e - Equipment/5e - Attunement/5e - Symbiotic Nature (Property)|🎒Symbiotic Nature]] property without it counting toward the maximum number of magic items you can attune to. In addition, whenever you finish a **Long Rest**, you can end your Attunement to a magic item that has the [[02. Regelwerk/D&D 5e Regelwerk/5e - Basic Rules/5e - Equipment/5e - Attunement/5e - Symbiotic Nature (Property)|🎒Symbiotic Nature]] property. When doing so, you can ignore any restrictions that require you be targeted by a [[02. Regelwerk/D&D 5e Regelwerk/5e - Combat/5e - Spellcasting/5e - Spell Schools/5e - Spellschool Abjuration/5e - Level 3 Abjuration/5e - Remove Curse (Spell)|☄️Remove Curse]] spell or similar magic before the symbiont can be removed.
