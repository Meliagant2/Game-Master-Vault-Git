# 🥇5e - Medic🥇

> [!wikibox]
> | | |
> |---|---|
> |**Category**|Skill |
> |**Level Requirement**|2 |
> |**Prerequisite**| |
> |**Repeatable**| |

You gain the following benefits:

**<u>Skill Proficiency:</u>** You gain [[02. Regelwerk/D&D 5e Regelwerk/5e - Basic Rules/5e - Skills/5e - INT Skills/5e - Medicine|💃Medicine]] [[02. Regelwerk/D&D 5e Regelwerk/5e - Basic Rules/5e - D20 Tests/5e - Proficiency/5e - Proficiency|🎲Proficiency]], or one level of [[02. Regelwerk/D&D 5e Regelwerk/5e - Basic Rules/5e - D20 Tests/5e - Proficiency/5e - Expertise|🎲Expertise]], if you are already _proficient_.

**<u>Field Medic:</u>** You can tell by looking at a creature if it is missing any of its _Hit Points_ and whether or not it is [[02. Regelwerk/D&D 5e Regelwerk/5e - Basic Rules/5e - Conditions/5e - Bloodied|☠️Bloodied]]. You can also attempt to end a [[02. Regelwerk/D&D 5e Regelwerk/5e - Basic Rules/5e - Conditions/5e - Conditions|☠️Condition]] currently affecting a creature within <u>5 feet</u> of you.

As a [[02. Regelwerk/D&D 5e Regelwerk/5e - Combat/5e - Actions, Bonus Actions & Reactions/5e - Actions/5e - Utilize|⚔️Utilize]] action you expend <u>one</u> use of a [[02. Regelwerk/D&D 5e Regelwerk/5e - Basic Rules/5e - Equipment/5e - Adventuring Gear/5e - Healers Kit|🪓Healers Kit]] and you make a **DC20 Medicine** [[02. Regelwerk/D&D 5e Regelwerk/5e - Basic Rules/5e - D20 Tests/5e - Ability Check/5e - Ability Check|🎲Check]]. _**Success:**_ You end one of the following <u>Conditions</u> on the creature. If one of those <u>Conditions</u> has more than one stacks afflicting the target (like the [[02. Regelwerk/D&D 5e Regelwerk/5e - Basic Rules/5e - Conditions/5e - Bleeding|☠️Bleeding]] <u>Condition</u>), you end all stacks at once: [[02. Regelwerk/D&D 5e Regelwerk/5e - Basic Rules/5e - Conditions/5e - Bleeding|☠️Bleeding]], [[02. Regelwerk/D&D 5e Regelwerk/5e - Basic Rules/5e - Conditions/5e - Blinded|☠️Blinded]], [[02. Regelwerk/D&D 5e Regelwerk/5e - Basic Rules/5e - Conditions/5e - Deafened|☠️Deafened]], [[02. Regelwerk/D&D 5e Regelwerk/5e - Basic Rules/5e - Conditions/5e - Paralyzed|☠️Paralyzed]], [[02. Regelwerk/D&D 5e Regelwerk/5e - Basic Rules/5e - Conditions/5e - Poisoned|☠️Poisoned]].
