Regelwerk/D&D 5e Regelwerk/5e - Basic Rules/5e - Equipment/5e - Elixirs/5e - Antitoxin|🍶Antitoxin]], as long as you have an empty [[02. Regelwerk/D&D 5e Regelwerk/5e - Basic Rules/5e - Equipment/5e - Adventuring Gear/5e - Vial|🪓Vial]] or [[02. Regelwerk/D&D 5e Regelwerk/5e - Basic Rules/5e - Equipment/5e - Adventuring Gear/5e - Flask|🪓Flask]]. These liquids evaporate when you finish another **Long Rest**.
