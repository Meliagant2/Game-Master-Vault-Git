# 🥇5e - Religious Training🥇

> [!wikibox]
> | | |
> |---|---|

> |**Prerequisite**| |

You gain the following benefits:

**<u>Skill Proficiency:</u>** You gain [[02. Regelwerk/D&D 5e Regelwerk/5e - Basic Rules/5e - Skills/5e - Knowledge Skills/5e - Religion|💃Religion]] [[02. Regelwerk/D&D 5e Regelwerk/5e - Basic Rules/5e - D20 Tests/5e - Proficiency/5e - Proficiency|🎲Proficiency]], or one level of [[02. Regelwerk/D&D 5e Regelwerk/5e - Basic Rules/5e - D20 Tests/5e - Proficiency/5e - Expertise|🎲Expertise]], if you are already _proficient_.

**<u>Religious Information:</u>** When you are in contact with a holy relic, religious artifact, or any kind of similar object or structure, you can learn something about it. You receive a correct answer from the GM for a reasonable question about the object that can be answered with a _yes_ or _no_. The GM decides what a _reasonable_ question is.

**<u>Number of Uses:</u>** You can use this feature a number of times equal to <u>your PB</u>, and you regain all expended uses when you finish a **Long Rest**.
