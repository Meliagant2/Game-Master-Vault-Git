# 5e - Changelog - Tungdil 1

Why did I write everything in english? Because I dislike having 2 languages in one document.

## General Changes

_**<u>THERE ARE MORE CHANGES THAN THIS, BUT THESE ARE THE CHANGES DIRECTLY INFLUENCING YOU, OR THAT ARE GENERALLY GOOD TO KNOW!!!</u>**_

### New Character Sheet

There is a new designed Character sheet to hold all the new information. You can find that on my discord Server or as a PDF in the Signal Group Chat.

### Conditions

**<u>Exhaustion:</u>** There might now be effects targeting Exhaustion. In that case, both Fatigue and Strife are affected.
**<u>Fatigue:</u>** Now scales from 1-5 instead of 1-10. 1 level doesn't reduce a d20 roll by 1, but by 2 and for each level of Fatigue, the creatures speed is reduced by 5 feet.
**<u>Strife:</u>** Now scales from 1-5 instead of 1-10. 1 level doesn't reduce a d20 roll by 1, but by 2.
**<u>Grappled:</u>** A grappled creature now has **DISADV** on attacks against creatures other than the grappler.

### Feats

**<u>Feat Categories:</u>** Now categorized into Origin, Class, General and Skill Feats. Each character gains one Class, General and a Skill feat every 2nd level (See below).

### Languages

**<u>Language Mastery:</u>** [[02. Regelwerk/D&D 5e Regelwerk/5e - Basic Rules/5e - Languages/5e - Languages|Languages]] now have 3 levels of mastery: Speaking, Reading, Signing. Whenever a character learns a language, they increase that language's mastery by one level, unless stated otherwise.

### Skills and Proficiency

**<u>Skill Categorization:</u>** Skills are now categorized under the ability scores. They can still be used with different ability scores, but this makes it easier to call for checks.
**<u>Expertise Die:</u>** Removed. Instead there is a new system for [[02. Regelwerk/D&D 5e Regelwerk/5e - Basic Rules/5e - D20 Tests/5e - Proficiency/5e - Expertise|Expertise]] levels. Simply put: Each point of Expertise equals a +1 in that skill to a max of the associated Ability score or `+5`, whichever is lower.
**<u>Skill Specialties:</u>** Removed. This includes Scent specialty for Perception, Swimming for Athletics, Fey for Arcana etc.
**<u>Animal Handling:</u>** Removed
**<u>Breaking:</u>** New STR Skill.
**<u>Endurance:</u>** New CON Skill.
**<u>Hold Breath:</u>** New CON Skill.
**<u>Intimidation:</u>** Now a STR Skill, but I will still allow using CHA for it instead.
**<u>Medicine:</u>** Now an INT check instead of WIS.
**<u>Occultism:</u>** New INT Knowledge Skill.
**<u>Revelry:</u>** New CON Skill.

### Spellcasting

**<u>Spell Lists:</u>** Removed Class specific lists, added **Occult** spell source. Now the 4 Spell sources are: Arcane, Divine, Occult, Primal. Each Class gains access to one of those Spell sources. This might cause additions or removals of spells you currently have access to.
**<u>Spell Changes:</u>** Too many to list here. The ones relevant for your character are detailed at the end of this changelog.
**<u>Spellcasting Foci:</u>** [[02. Regelwerk/D&D 5e Regelwerk/5e - Basic Rules/5e - Equipment/5e - Spellcasting Focus/5e - Spellcasting Focus|Spellcasting Foci]] now act as weapons with properties and mastery properties.
