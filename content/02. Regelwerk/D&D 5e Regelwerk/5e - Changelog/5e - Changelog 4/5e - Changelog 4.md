# 5e - Changelog 4

## Class Changes

### General Class Changes

**Class Table:** Reworked the class table. Classes now gain class features at levels 1, 5, 9, 13, 17 and 20, and subclass features at levels 3, 7, 11, 15 and 19. At every even level, every class gains a _class feat_, a _general feat_ and a _skill feat_.
**Maneuvers and Spellcasting:** Removed the "Combat Maneuvers" and "Spellcasting" features from every classes class feature list and moved them into "core class traits". Simplyfied the wording of those features.
**Martial Class Maneuvers:** Now every martial class gains access to the same number of maneuvers and exertion points at any given level. Changed the Maneuver traditions and some maneuvers (See maneuver changes below).
**Martial Class Fighting Styles:** Every martial class now gains access to one "Fighting Style" class feat at character creation.
**Martial Class Weapon Masteries:** Every martial class now gains access to "Weapon Masteries" (See weapon changes below).
**Martial Class Extra Attack:** Removed "Extra Attack" from martial classes class features and moved them into "core class traits". Every martial class now gains a 2nd attack at 5th level, a 3rd at 11th and a 4th at 17th level, distributing martial class power scaling evenly.
**Saving Throw Proficiencies:** Every class can now choose their 2 starting saving throw proficiencies, out of a set of 4 listed proficiencies.
**Subclasses:** All Subclasses are now "Archetypes" of a specific class, allowing for more general character customization.
